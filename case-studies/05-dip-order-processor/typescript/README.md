# TypeScript Implementation

## Prerequisites

-  Node.js (v18 or higher)
-  npm

## Setup

1. Navigate to this directory:
   ```bash
   cd case-studies/05-dip-order-processor/typescript
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

## How to Run

### The "Bad" Version

This version violates the Dependency Inversion Principle.

```bash
npm run start:bad
```

### The "Good" Version

This version adheres to the Dependency Inversion Principle.

```bash
npm run start:good
```
